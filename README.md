# Учебный лендинг фотографа

Адаптивный демонстрационный сайт, созданный по требованиям опубликованного заказа. Это учебный проект, а не оплаченная работа для реального клиента.

## Состав

- `index.html` — структура и текст страницы.
- `styles.css` — оформление и адаптивность.
- `script.js` — учебное поведение формы без отправки данных.
- `images/` — локальные оптимизированные изображения WebP.
- `image-sources.md` — происхождение учебных фотографий.
- `client-brief.md` — вопросы для сбора материалов у заказчика.

## Важно

Имя, город, цены, отзывы и контакты на странице вымышлены. Форма проверяет обязательные поля, но никуда не отправляет данные. Перед использованием для настоящего клиента нужно получить и согласовать его материалы, контакты, условия услуг и способ получения заявок.

Локальный запуск из папки проекта:

```powershell
python -m http.server 8001 --bind 127.0.0.1
```

После запуска сайт доступен по адресу <http://127.0.0.1:8001/>.
